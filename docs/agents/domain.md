# Domain docs

## Client relationship

Rust Athena is the server for the Rodecomp client. Consult the client repository when working on client compatibility or behavior that crosses the client-server boundary. [Rodecomp client](https://github.com/rodecomp/rodecomp)

## Before exploring

- Read the root `GLOSSARY.md` and relevant decisions in `docs/adr/` when present.
- Use glossary terms in issues, proposals, hypotheses, and tests. Note gaps for the domain-modeling skill.
- Flag any conflict with an existing ADR and explain why the decision might need revisiting.

The domain-modeling skill creates glossary and ADR files as terms and decisions are settled.
